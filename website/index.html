Cómo se usa

Sprite

Un solo archivo para toda la biblioteca.

<svg width="24" height="24">
  <use href="sprite.svg#ai-hen"/>
</svg>

CSS

Hereda color y tamaño del texto que lo rodea.

<link rel="stylesheet"
      href="avivet-icons.css">

<i class="ai ai-hen"></i>

React

Decorativo por defecto; con title pasa a anunciarse.

import { Hen } from '@avivet/icons-react'

<Hen size={24} />
<Hen title="Gallina" />

Vue

Mismo contrato de props que React.

import { Hen } from '@avivet/icons-vue'

<Hen :size="24" />

SVG suelto

Para Word, PowerPoint o Canva.

packages/core/svg/animals/hen.svg

JSON

Para construir tus propias herramientas.

import m from '@avivet/icons-json'

m.icons.find(i => i.id === 'hen')
