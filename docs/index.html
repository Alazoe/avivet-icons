Cómo se usa

Sprite

Un solo archivo para toda la biblioteca. Ideal para sitios web.

<svg class="ai">
  <use href="sprite/avivet-icons.svg#ai-hen"/>
</svg>

CSS

Hereda color y tamaño del texto que lo rodea.

<link rel="stylesheet"
      href="css/avivet-icons.css">

<i class="ai ai-hen"></i>
<i class="ai ai-lg ai-egg"></i>

SVG suelto

Para Word, PowerPoint o Canva: descarga el archivo de src/.

src/animals/hen.svg
src/water/nipple-drinker.svg
